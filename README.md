# StudySpace

A student assignment tracker for keeping deadlines, priorities, and coursework in one place.
As a student myself I decided to build something that will make my life easier. 

## Features

- Add assignments with a module, due date, priority, and status.
- See upcoming and overdue deadlines.
- Search assignments and filter by status or subject.
- Mark assignments as complete, reopen them, or delete them.
- Save assignments in the browser so they’re still there after a refresh.
- Use the tracker on desktop or mobile.

## Built with

- HTML
- CSS
- JavaScript

## Run it

Download the project files and open `index.html` in a web browser.

> Assignments are saved in the browser on the device where they were added.
